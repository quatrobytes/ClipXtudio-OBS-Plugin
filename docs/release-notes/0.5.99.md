# ClipXtudio 0.5.99

## Default capture format

- New installations and new settings profiles start with **Vertical** as the default clip format.
- The first-run assistant selects **Vertical** automatically.
- Choosing **Later** in the assistant does not change the default back to Horizontal.
- Free accounts can use the basic 9:16 export generated from the main OBS output.
- Creating Horizontal and Vertical copies together remains a Pro feature.

Existing installations keep the format the user already selected; the update does not overwrite an intentional saved preference.
