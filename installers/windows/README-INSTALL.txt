ClipXtudio v0.5.91 - instalación manual

1. Cierre OBS Studio si no está grabando ni transmitiendo.
2. Copie la carpeta clipxtudio completa en:
   C:\ProgramData\obs-studio\plugins\
3. Inicie OBS Studio.
4. Abra el panel desde Docks > ClipXtudio si no aparece automáticamente.

Para desinstalar manualmente, cierre OBS y elimine únicamente:
C:\ProgramData\obs-studio\plugins\clipxtudio

La desinstalación no elimina clips, exportaciones, miniaturas, ajustes ni la
biblioteca local del usuario.

Esta compilación pública requiere HTTPS para licencias y no contiene licencias
QA ni secretos privados.
